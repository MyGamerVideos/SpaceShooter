# SpaceShooter
instructions: use the arrow keys or W A S D to move, press space or hold down the mouse to shoot. the player points in the direction of the mouse. you have 500 hp that regenerates. Events are little things that change the gameplay. events happen every 60 seconds, and last 30 seconds. Press M to view a guide for all the types of cookies.
